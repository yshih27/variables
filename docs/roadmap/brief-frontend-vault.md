# Executor WP — your vault, valued, frontend: paste a wallet, read what it is worth and why

Frontend executor, Varible. One PR fresh off `origin/main` (e.g. `feat/vault`), pushed, opened against main, NO merging. Own worktree with the three symlinks; `--webpack`; NEXT_PUBLIC_SHELL_V2=true; tsc/eslint/build clean; truthful trailer. Builds against the backend contract in `brief-backend-vault.md` (`getVaultValuation`, `VaultValuation`, `parseWalletAddress`); if the backend PR is not merged yet, stack on its branch with `--base` and say so. Design: bet 2 in `docs/roadmap/features-roadmap.md`. The page must read like a statement from a custodian, not a portfolio app: every figure with its basis and its n, nothing typed.

## The surfaces
1. **`/vault`** — the door. One input ("a Solana, Polygon or Base address"), one button, the chain detected client-side with `parseWalletAddress` as the user types (a small chip: `Solana` / `Polygon + Base`; an invalid input says why, in a receipt line, never a red banner). Submit navigates to `/vault/<address>`. Below the input: addresses looked up on this device (localStorage, the watchlist's pattern in `src/lib/watchlist.ts`, at most 5, short form `0x12ab…9f3c` / `7GkP…2mQ4`, each a link and a remove). A `ReadMe` line ≤ 12 words: what the page reads and that nothing is stored.
2. **`/vault/<address>`** — the statement (server-rendered from `getVaultValuation`; `robots: { index: false, follow: false }`; `force-dynamic`). Header: the address short form with a copy button ("Copied"), the chain chip, `as of <asOf>` and `method v4.2` as one receipt line. KPI strip (StatCard): `Holdings` (n, with the venue split in its foot: `Collector Crypt 12 · Beezie 4 · Courtyard 3 unkeyed`), `Valued` (`n of N`, coverage %), `Value` (`atValue.usd`, foot: `reference n · last sale n`), `At floor` (`atFloor.usd`, foot: `n plausible asks`), `Spread` (`spread.usd`, `spread.pct`, foot `over n with both`). A total without an n is never printed; a null spread prints `—` with `no holding has both a price and a floor`.
3. **The §7 pair** — `By IP` ‖ `By grade`: two bar lists on the `atValue` basis (label, holdings, value, share of value), same height, tops and bottoms aligned (measured 0 px), stacking below `lg`. `byVenue` is the KPI foot, not a third panel.
4. **The holdings table** — one row per slab: `CardThumb` (hover/tap preview as everywhere), name linking to `/i/<slug>` (or plain text with a `no identity yet` chip and its reason when `identity` is null), `GradeChip`, venue, `Reference` (`$323 · Aug · n 5`, `thin` chip when thin), `Last sale` (`$255 · Sep 9`), `Floor` (`$300` when plausible; `unverified ask $1.84` in `text-ink-3` when not — never in the value column), `Your ask` when this slab is listed, `Value` with a basis chip (`reference` / `last sale`). Sorted by value desc; sortable by value, name, venue, grade (the machines table's control). Unvalued rows sit in their own group at the bottom under one line: `n slabs without a value · no sale yet n · no identity n`. Rows beyond 25 fold behind "Show all". A `partial` result prints one receipt line above the table with the reason and the count reached; it does not hide the rows it has.
5. **Export and share.** `CSV` downloads every row with every column and the basis (the `IndexStudio` Blob pattern; filename `varible-vault-<short>.csv`); `Share` copies the page URL. No "connect wallet" in this PR: paste is the whole surface, and the brief for wallet adapters comes after this ships.
6. **Nav.** `Vault` in `NavBar`, `BottomTabs` and the `CommandPalette`; a `⌘K` entry "Value a wallet" that focuses the input.
7. **Empty and error states, each a real page.** Invalid address: the door with the reason. Valid address, no tracked holdings: the statement header with `no slabs from tracked venues in this wallet` and the list of venues read. Backend timeout / partial: the statement with its receipt line. None of them is a generic error page.

## Constraints
readMe ≤ 12 words and mode-true; no new colours (basis chips use the existing chip palette; grade colours are `GradeChip`'s); zero reads beyond `getVaultValuation`; §7 where the pair appears; a floor or an ask is never summed into a value anywhere on the page; every total prints its n; copy says `venue`, `slab`, `identity`, `reference price`, and Beezie's machine is the Claw if it is ever named. Mobile: the table scrolls inside its own container; the KPI strip wraps to two rows; `scrollWidth === innerWidth` at 375.
